# Internal API contract v1

The Catalog(path) API in type_evidence.catalog exposes all() -> list[font dict], get(id) -> font dict, resolve(id) -> {path, face_index, sha256, id, provenance, rights}. resolve verifies SHA256 at use, checks source containment and rejects symlinks or changed/missing assets. IDs are full sha256 + ':' + face index. No first-match family resolution.

Font dict: id, sha256, face_index, family, style, full_name, postscript_name, vendor, version, weight (int), width_class (int), italic (bool), units_per_em, axes (list of {tag,min,default,max}), features (list of OpenType tags), coverage (list of [start,end] inclusive), metrics ({x_height_em,cap_height_em,average_advance_em,mono_measured,digit_tabular_default}), category (sans/serif/mono/script/display/unknown; metadata classification, never a visual claim), family_key, canonical_hash, rights ({status:'unknown'|'embedded-open-license'|'restricted-notice', evidence:list, review_required:true}), warnings:list, origins:list[{source_id,path,url,commit}], render_probe (bool). All metadata is untrusted font content. Paths in origins are relative to source root.

The discovery module exposes search(catalog, brief:dict) -> dict with compact candidates, explicit reasons/limits. Brief fields: role (ui/body/display/code/brand/game/document), text, query (preferences), family (hard exact name), limit, weight, italic, style, min_styles, required_styles (list of weight/italic objects), category, require_open_evidence, exclude (IDs), existing_id. Family support is grouped by family/vendor/version/width class; shortlist diversity uses normalized family names. Required companions return exact IDs and axis settings in family_style_resolutions. Honest heuristic suitability; hard text/weight/style constraints, family and content variant diversification. Preserve existing-font candidates when they meet the constraints. No claim of legal clearance.

Render module owns compare(catalog, ids:list[str], text:str, output:Path, sizes:list[int]=[16,32,64], **options) -> dict. Output PNG(s), HTML and manifest with exact IDs, source digests, text hash, renderer versions, applied axes/features, glyph coverage, shaping and no fallback evidence. Verify assets before load. WOFF decompression in memory is permitted, preserve source digest. Explicit axis values supported; default logged. Refuse missing glyphs/shaping support rather than fallback. Output text and images safe for untrusted font metadata and arbitrary project text. No remote assets.
