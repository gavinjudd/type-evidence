Know what you are seeing.

No fonts load from external services when you browse. Family names are directory labels, set in this interface’s system font.

“Load Google preview” requests that family’s font stylesheet and files from Google Fonts. Changing the specimen may load additional character subsets for that family. Your browser connects to Google; your custom specimen text is not included in the request. A preview appears only after the browser confirms that a font face loaded.

We show the requested regular weight or the closest declared upright style. The loaded status confirms a browser face, not coverage for every character, every weight, or suitability for your project.

Commercial fonts are metadata and provider links only. View the actual type on its provider’s site and check its current license. No commercial font files are loaded here.

Search uses declared metadata, not the local toolkit’s optional visual model. Shortlists and project notes use this browser’s local storage.
